# Guanux-analog_operation_system
Guanux模拟操作系统是一个基于thinkphp的Web端模拟操作系统，操作系统的主要算法实现采用的是javaScript语言，其主要功能分为三个部分，一是文件管理与用户接口，可以通过输入文件操作命令在系统磁盘中创建目录、删除目录、跳转目录、创建文件、删除文件、编辑文件、拷贝文件、移动文件、修改文件属性以及格式化；二是内存管理，可以输入操作初始化内存、装入作业和回收作业；三是进程管理与设备管理，可以加入进程，将进程运行过程例如内存条的变化、中间结果、当前正在运行的进程、就绪进程、阻塞进程以及设备使用情况等信息显示在屏幕上。该系统用到的技术栈包括html、css、js、jq、thinkphp5.1、bootstrap前端框架，目前该系统仍处于不断迭代更新的状态。
